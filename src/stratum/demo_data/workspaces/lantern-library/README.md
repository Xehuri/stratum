# Lantern Library

A synthetic reading club workspace used by the Stratum demo.

Every title, session, measurement and note in this workspace is invented. The
workspace exists to demonstrate heading blocks, a Markdown table, a fenced code
block and a contract-shaped claim document.

## About the club

The club meets in a fictional reading room and records short reading sessions.
There is no real person, place or private data behind any of these notes.

## Workspace layout

- `reading-log.md` contains atomic claim-shaped entries.
- `notes/the-dispossessed.md` is a legacy narrative fixture.
